# مستقبلي الدراسي | MY STUDY FUTURE

منصة تعليمية عراقية عربية RTL تربط الطالب بالمدرس وتجمع المراحل الدراسية والدورات في واجهة واحدة.

## ما تم بناؤه
- واجهة عربية RTL متجاوبة بهوية بصرية حديثة.
- Supabase Auth: إنشاء حساب طالب أو مدرس بالبريد، تسجيل الدخول والخروج، واستعادة كلمة المرور.
- ملفات مدرسين عامة تقرأ من قاعدة البيانات.
- عرض الدورات المنشورة مع البحث والتصفية حسب المرحلة.
- لوحة الطالب: عرض طلبات التسجيل والحجوزات ونتائج الاختبارات.
- لوحة المدرس: إنشاء دورات كمسودات وعرض الحجوزات الواردة.
- قاعدة بيانات Supabase تشمل الملفات الشخصية والمواد والدورات والدروس والتسجيلات والحجوزات والتقييمات والاختبارات.
- حماية RLS، ومنع تغيير دور الحساب إلى admin من واجهة العميل، ومنع نشر الدورة قبل مراجعة الإدارة.
- إعداد PWA وService Worker وNetlify static publish.

## حدود النسخة الحالية قبل الإطلاق التجاري
- لا توجد بوابة دفع حقيقية؛ تفعيلها يتطلب موافقة المزود ومفاتيح API الرسمية.
- لا توجد لوحة إدارة ويب مكتملة بعد؛ الدورات الجديدة تبقى مسودات حتى تعتمدها الإدارة.
- يلزم إعداد SMTP موثوق لتأكيد البريد واستعادة كلمة المرور.
- لا يوجد حالياً نظام رسائل داخلية أو حصص فيديو مباشرة أو محتوى تعليمي مرخّص.
- يجب استكمال سياسة الخصوصية وشروط الاستخدام وحماية القاصرين واختبارات قبول وأمن قبل الإطلاق العام.
