# مستقبلي الدراسي | MY STUDY FUTURE

منصة تعليمية عراقية عربية RTL تربط الطالب بالمدرس وتجمع المراحل الدراسية والدورات في واجهة واحدة.

## ما تم بناؤه في النسخة الحالية
- واجهة عربية RTL متجاوبة بهوية بصرية حديثة.
- Supabase Auth: إنشاء حساب طالب أو مدرس بالبريد، تسجيل الدخول والخروج، استعادة كلمة المرور وتعيين كلمة مرور جديدة.
- ملفات مدرسين عامة، عرض الدورات المنشورة والبحث والتصفية حسب المرحلة.
- لوحة الطالب: طلب التسجيل، طلب حجز درس من دورة، متابعة حالة التسجيل والحجز، ومشاهدة الدروس بعد قبول التسجيل.
- لوحة المدرس: إنشاء دورات كمسودات، إضافة دروس وروابط فيديو HTTPS، مراجعة طلبات التسجيل وقبولها أو رفضها، وتأكيد الحجوزات أو إلغاؤها.
- قاعدة بيانات تشمل الملفات الشخصية والمواد والدورات والدروس والتسجيلات والحجوزات والتقييمات والاختبارات.
- سياسات RLS على جميع جداول public، وحماية بيانات ملفات الطلاب، ومنع ترقية الحساب إلى admin من العميل.
- الدورات لا تُنشر من حساب المدرس مباشرة؛ تبقى مسودات حتى مراجعة الإدارة.
- PWA manifest وService Worker وأيقونة وترويسات أمان على Netlify.
- صفحات عربية أولية لسياسة الخصوصية وشروط الاستخدام.

## ما يمنع الإطلاق التجاري الكامل حتى الآن
- مشروع Netlify موجود لكنه لا يحتوي على أي Deploy منشور؛ يجب إكمال ربط GitHub بالمشروع من لوحة Netlify حتى يبدأ النشر التلقائي.
- لا توجد لوحة إدارة ويب نهائية لإدارة المستخدمين والمحتوى والبلاغات.
- لا توجد مدفوعات حقيقية أو تكامل ZainCash مفعّل؛ يلزم اعتماد المزود ومفاتيح API الرسمية.
- يجب ضبط SMTP موثوق لتأكيد البريد واستعادة كلمة المرور.
- لا توجد حالياً منصة فيديو مباشرة أو محادثات داخلية أو نظام اختبارات متكامل؛ جداول الاختبارات موجودة لكن واجهة أداء الاختبار لم تُفعّل.
- صفحات الخصوصية والشروط مسودات أولية وليست مراجعة قانونية نهائية.
- يجب استكمال موافقات ولي الأمر وضوابط حماية القاصرين، واختبارات قبول على متصفح وهاتف، ومراجعة أمنية وقانونية قبل استقبال بيانات حقيقية.

## إعداد Netlify
ملف `netlify.toml` يحدد مجلد النشر `.` دون build command. اربط المستودع أعلاه على الفرع `main` بمشروع Netlify الحالي.
