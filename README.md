# مستقبلي الدراسي | MY STUDY FUTURE

منصة تعليمية عراقية تجمع الطلاب والمدرسين وتدعم المراحل الدراسية من الابتدائية إلى الجامعة، إضافة إلى الدورات والمهارات.

## الحالة الحالية
- واجهة أولية عربية RTL ومتجاوبة مع الهاتف والكمبيوتر.
- اختيار المسار الدراسي والبحث ضمن بيانات العرض التجريبية.
- أساس أولي لتجربة PWA والعمل دون اتصال لبعض الملفات.
- إعداد نشر ثابت على Netlify.

## ما لم يُفعّل بعد
- تسجيل الدخول وإنشاء الحسابات.
- الربط التشغيلي مع Supabase وجلب بيانات المدرسين والمواد.
- لوحة المدرس ولوحة الإدارة والحجوزات والدفع.
- الذكاء الاصطناعي التعليمي.

لا تمثل بطاقات المواد الحالية مدرسين حقيقيين أو بيانات مباشرة؛ إنها عناصر عرض مؤقتة إلى حين ربط قاعدة البيانات.

## النشر
يمكن نشر جذر المستودع على Netlify دون أمر بناء، مع مجلد نشر `.`.
