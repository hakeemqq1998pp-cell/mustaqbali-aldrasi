شروط الاستخدام

مسودة تشغيلية بتاريخ 10 نوفمبر 2026. لا تعتمد تجارياً قبل مراجعتها قانونياً في العراق.

تحدد هذه الشروط القواعد العامة لاستخدام منصة مستقبلي الدراسي، وهي منصة تقنية لتنظيم الوصول إلى الدورات والمدرسين والخدمات التعليمية.

1. طبيعة الخدمة

تربط المنصة الطلاب بالمدرسين وتوفر أدوات للدورات والدروس والتسجيل والحجوزات والاختبارات. لا تضمن المنصة نتائج دراسية أو قبولاً مدرسياً أو جامعياً أو اعتماداً رسمياً لأي محتوى.

2. الحسابات والمسؤولية

يلتزم المستخدم بتقديم بيانات صحيحة، والمحافظة على سرية كلمة المرور، وعدم مشاركة الحساب أو استخدامه لانتحال شخصية الغير. يتحمل المستخدم مسؤولية الأنشطة التي تتم عبر حسابه ما لم يثبت اختراقه أو إساءة استخدامه.

3. حساب الطالب

طلب التسجيل أو الحجز لا يعني القبول أو التأكيد تلقائياً. يجب متابعة الحالة الظاهرة داخل الحساب، وعدم مشاركة معلومات حساسة أو بيانات الدخول مع أي شخص.

4. حساب المدرس

يلتزم المدرس بصحة بياناته وبحقوق الملكية الفكرية للمحتوى، واحترام الطلاب وخصوصيتهم. تخضع ملفات المدرسين والدورات لمراجعة الإدارة قبل ظهورها للعامة. يحظر طلب بيانات شخصية غير لازمة أو استغلال الطلاب أو التواصل المخالف للقانون.

5. القاصرون والسلامة

يجب احترام حقوق القاصرين وخصوصيتهم والحصول على موافقة ولي الأمر حيثما يتطلب القانون ذلك. يمنع التحرش أو الاستغلال أو طلب صور أو معلومات حساسة أو محاولة نقل التواصل إلى قنوات غير آمنة.

6. المحتوى والملكية الفكرية

يحظر نشر محتوى مخالف للقانون أو منتهك لحقوق النشر أو مضلل أو مسيء. يحتفظ صاحب المحتوى بحقوقه، ويمنح المنصة فقط الأذونات الضرورية لتشغيل الخدمة وعرض المحتوى وفق اتفاق واضح.

7. الرسوم والمدفوعات

لا توجد مدفوعات إلكترونية مفعلة حالياً. لن تعتبر أي عملية دفع نافذة إلا بعد تفعيل مزود دفع رسمي، وإظهار السعر والرسوم وشروط الإلغاء والاسترداد بوضوح قبل الدفع.

8. الإشراف وتقييد الحسابات

يجوز تقييد أو تعليق الحسابات أو المحتوى الذي يخالف الشروط أو يعرض المستخدمين للخطر، مع توفير آلية اعتراض وشكاوى واضحة في النسخة النهائية.

9. توفر الخدمة وحدود المسؤولية

قد تتوقف الخدمة مؤقتاً للصيانة أو بسبب أعطال لدى مزودي الخدمة. يجب استكمال أحكام المسؤولية والقانون المختص وآلية الشكاوى في النسخة النهائية بعد استشارة قانونية عراقية.
